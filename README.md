# EMF Compat Basic Weapons

Client-side Fabric compat so [Basic Weapons](https://www.curseforge.com/minecraft/mc-mods/basicweapons) plays nicer with EMF player models (Fresh Animations and Punchy, specifically), using [EMF Compat Core](https://www.curseforge.com/minecraft/mc-mods/emf-compat-core).

Inspired by Stradat's **EMF Compat** mods.

## What it does

- Adjusts the Pike's third-person animations (for Fresh Animations: Player Extension) and first person animations (for Punchy);
- Punchy attack gate for pikes / glaives / quarterstaves / clubs / hammers when you're swinging at a block (stops the animation from restarting forever when holding left click);
- Creative: None of the weapons can break blocks like tools, keeping the functionality similar to vanilla's weapons.

## Requirements

- Minecraft 26.1.2
- Fabric Loader + Fabric API
- Basic Weapons (≥ 2.4.1)
- Entity Model Features (≥ 3.3.2)
- EMF Compat Core (≥ 2.0.0)

**Optional:** [Punchy!](https://www.curseforge.com/minecraft/mc-mods/punchy) (≥ 2.8) for the FP / attack-gate bits

Client only

## Installation

Drop the jar in `mods` with the dependencies above. That's it.
